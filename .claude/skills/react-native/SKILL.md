# UI Conventions

Ensure that UI is consistent across the two platforms (iOS and ANdroid). Use there's a style or technique to use to ensure uniformity, use it rather than platform-specific (e.g `platform.os checks`) code. If a platform-specific implementation is required, document it in the code and in this skill. Use platform specific code sparingly, and only when necessary.
